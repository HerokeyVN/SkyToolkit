# SkyToolkit

SkyToolkit is an unofficial Windows plugin for **Sky: Children of the Light**.
This repository provides ready-to-use DLL releases for players using
[SkyLoader](https://github.com/HerokeyVN/SkyLoader).

[![Latest release](https://img.shields.io/github/v/release/HerokeyVN/SkyToolkit?label=latest)](https://github.com/HerokeyVN/SkyToolkit/releases/latest)
[![Downloads](https://img.shields.io/github/downloads/HerokeyVN/SkyToolkit/total)](https://github.com/HerokeyVN/SkyToolkit/releases)

## Download

Download `sky-toolkit.dll` from the
[latest release](https://github.com/HerokeyVN/SkyToolkit/releases/latest).

> [!IMPORTANT]
> Download the DLL only from this repository's **Releases** page. A source-code
> download from GitHub does not contain the ready-to-use plugin.

## Requirements

- Windows 10 or Windows 11, 64-bit
- The Steam PC version of Sky: Children of the Light
- [SkyLoader](https://github.com/HerokeyVN/SkyLoader)

## Installation

1. Install and open SkyLoader.
2. Click **Add DLL...** and select `sky-toolkit.dll`.
3. Select SkyToolkit and enable **Auto Update** if desired.
4. Launch Sky through SkyLoader.
5. Press `Alt + \`` to show or hide SkyToolkit.

When automatic updates are enabled, SkyLoader verifies the downloaded DLL
before replacing the installed version. Close Sky before applying an update.

## Highlights

- Player movement, visual and quality-of-life controls
- Outfit browser with cosmetic icons and dye controls
- Farming tools for candles, wing light, dye plants and Eden
- Teleport coordinates, D-pad movement, worlds and saved locations
- Social and account tools
- Searchable settings and customizable keyboard shortcuts
- Dark and light interface themes

> [!WARNING]
> SkyToolkit is an unofficial community project. Game updates may temporarily
> break some features. Use it at your own risk and keep backups of anything
> important.
